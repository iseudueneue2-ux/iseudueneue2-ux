# Cryvex — сайти, боти та автоматизація

Я — розробник-початківець у фрілансі. Створюю сайти, лендінги та автоматизацію: парсинг даних, моніторинг цін і Telegram-ботів.

### [Відкрити моє портфоліо](https://iseudueneue2-ux.github.io/freelance-bots-portfolio/)

На сайті можна переглянути проєкти, спробувати інтерактивні демо та перейти до коду.

| Проєкт | Що робить |
| --- | --- |
| [Misto Coffee](https://iseudueneue2-ux.github.io/misto-coffee/) | Сайт кав’ярні з меню, фільтрами, сортуванням і кошиком; авторський концепт |
| [Парсер каталогу](https://github.com/iseudueneue2-ux/freelance-bots-portfolio/blob/main/bots/scraper.py) | Збирає дані з навчального сайту та експортує CSV/JSON |
| [Монітор цін](https://github.com/iseudueneue2-ux/freelance-bots-portfolio/blob/main/bots/price_monitor.py) | Порівнює ціни між запусками та створює звіт |
| [Telegram-бот витрат](https://github.com/iseudueneue2-ux/freelance-bots-portfolio/blob/main/bots/expense_bot.py) | Записує витрати та показує місячні підсумки |

Це навчальні роботи для фріланс-портфоліо. Код, тести й інструкції українською доступні у [репозиторії](https://github.com/iseudueneue2-ux/freelance-bots-portfolio).

**Технології:** Python, Beautiful Soup, SQLite, Telegram Bot API, GitHub Actions.

Відкритий до перших замовлень на невеликі задачі з автоматизації.
